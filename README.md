# 08-zustand

Local implementation of the GoIT React-08 NoteHub homework.

## Setup

1. Copy `.env.example` to `.env.local`.
2. Add your personal `NEXT_PUBLIC_NOTEHUB_TOKEN`.
3. If the app uses a custom deployment domain, set `NEXT_PUBLIC_SITE_URL` to its origin.
4. Run `npm ci`, then `npm run dev`.

The API token is personal. Do not commit `.env.local`.
